§Game Collection Tracker

§Program Info

The program entry point is main which instantiates a game_collection_tracker::GameCollectionTracker and calls its game_collection_tracker::GameCollectionTracker::menu_loop method. This method allows the user to perform the operations defined in the high level requirements section of the accompanying assignment document.

It does so whilst making use of structured and object-oriented programming principles; the use of procedures, classes and reusable components; appropriate input validation and error handling; logical, maintainable and scalable code and meaningful internal code comments.

When the game_collection_tracker::GameCollectionTracker::menu_loop has been executed, the program terminates
